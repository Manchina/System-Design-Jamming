# Production TypeScript MCP Server with Zod Guardrails & AI Evals

## Architectural Scope
- Model Context Protocol (MCP) server built with the official TypeScript SDK.
- Exposes distributed systems inspection tools (Redis cache inspect, pgvector query, Snowflake generator, rate limiter telemetry).
- Input guardrails and schema validation with Zod.
- Automated evaluation harness benchmarking LLM tool-calling fidelity.
